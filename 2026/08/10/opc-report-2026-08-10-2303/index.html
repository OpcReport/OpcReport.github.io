Inference Just Got 80% Cheaper, But the Best Model Still Fails 89% of Real Legal Work

August 10, 2026 · Hourly Monitoring · 14 primary sources

Key Insights

Three things landed in the last 72 hours: inference pricing collapsed, coding agents went unsupervised by default, and five rival vendors agreed on a single plugin format. Together they close the “can I build it?” question for good.

Then Harvey open-sourced LAB and answered the other half: the best available model passes 11% of real legal tasks. Not multiple choice — actual law-firm assignments graded against 75,000+ expert-written criteria.

That contrast is the whole thesis. General capability is now abundant and nearly free. Domain reliability is still wide-open ground. The opportunity is no longer wrapping a model — it’s encoding what “correct” means in a specific industry. Whoever defines the eval defines whether the category can ship at all.

Numbers that actually change decisions:

  • GPT-5.6 Luna input dropped 80% — $6 → $1.20 per 1M tokens (~$1.40 blended). Terra fell 20% ($15 → $12). Batch-heavy products just got a new margin structure.
  • 11% pass rate on Harvey LAB — 1,671 real legal tasks, 24 practice areas, expert rubrics throughout.
  • 13.6% — the share of dangerous commands humans actually caught. That single stat is why Anthropic is flipping Claude Code to auto mode by default on August 14.
  • One plugin, six clients — Agent Plugins 1.0 makes a single package load in ChatGPT, Codex, Copilot, VS Code, Cursor, and Kiro.

Market Trends

1. Inference costs collapsed — “cheaper” is no longer a product

On July 30, OpenAI restructured GPT-5.6 pricing across the board. On August 6, free users got Luna as default with unlimited text chat.

Tier Before After Change
Luna (input / 1M) $6.00 $1.20 −80%
Terra (input / 1M) $15.00 $12.00 −20%
Sol Standard $30.00 $30.00 unchanged
Sol Fast (new, 2.5x throughput) — ~$70 blended new premium tier

Note what did not happen: the flagship never got cheaper, and a more expensive tier appeared. Vendors have concluded that people pay for certainty and speed, not for generation. Copy that logic into your own pricing.

Two consequences for solo builders:

  • Upside: workloads that were economically impossible are now trivial. Full-corpus document processing, exhaustive data cleaning, running every output through five self-checks — all fine on margin now.
  • Downside: any positioning built on “we’re cheaper” evaporated overnight. When free users get unlimited access to last-gen flagship quality, thin model-reselling has no room left.

2. Agents went unsupervised, and the accountability layer is missing

From August 14, Claude Code’s auto mode becomes default for Pro, Max, and Team. The agent runs without step-by-step approval, stopping only for actions flagged irreversible, destructive, or reaching outside the environment. Anthropic’s justification is blunt: humans were catching 13.6% of dangerous commands. Step-approval was security theater.

The same week, Claude Code 2.1.224 shipped cross-session messaging — agents in separate terminals can now exchange state and coordinate like people on a shared project. And on August 8, a developer launched claudiuswrld: a fully autonomous Claude agent with its own X account, a Browserbase browser, persistent memory, and a budget — no task, no prompt. Pure observation of what identity emerges.

The direction is unambiguous: agents are getting persistent runtime, cross-session memory, and spending authority. What they are not getting is a permissions, audit, and cost-brake layer. At Black Hat USA 2026, AI supply-chain security dominated CISO conversations, with well-funded agent-security startups filling the floor. A category called AISP (Agentic Identity and Security Platforms) is crystallizing — treating AI agents as first-class identities rather than service accounts, with real-time policy enforcement and continuous audit trails.

3. Plugin distribution got standardized — and that favors small builders

On August 6, OpenAI, Microsoft, AWS, Cursor, and Vercel jointly shipped Agent Plugins 1.0: an open standard packing Agent Skills and MCP server configs into one portable directory. Build once, load in ChatGPT, Codex, GitHub Copilot, VS Code, Cursor, and AWS Kiro. Spec and migration example are on GitHub (agentplugins/agent-plugins-example).

Anthropic — author of MCP — is not on the list. Worth watching as a fracture point, but it doesn’t change the takeaway: distribution just stopped being a big-company advantage. Six entry points, one build, and the users behind those doors already pay for tools.

Two more signals from the same window:

  • OpenAI acquired NextSlide (disclosed August 8; deal actually closed in early 2026). The team moved onto ChatGPT’s creation and communication tools. Generic productivity is now platform territory.
  • Soup CLI fine-tunes Llama-3.1-8B on a 4GB laptop GPU — 3.32GB peak, 119.6 tok/s — via layer streaming: the frozen base sits in CPU RAM, one decoder layer at a time enters VRAM.

Build Directions

Direction 1 — Turn domain correctness into an eval product ⭐ highest conviction

What: Pick a vertical you genuinely know (medical billing, claims adjudication, tax compliance, trade documentation, clinical trial docs). Decompose real deliverables into a task set with expert grading rubrics. Sell it as an ongoing evaluation service. Harvey proved with 1,671 tasks that frontier models sit at 11% — that gap is the product. Buyers aren’t purchasing a model; they’re purchasing the answer to “can I safely hand this process over?”

Stack: Inspect / inspect_scout for orchestration and agent-trace analysis · Langfuse or Braintrust for logging and regression diffs · GPT-5.6 Luna for bulk first-pass grading (tens of thousands of runs for double-digit dollars) · Sol for adjudicating disputed samples · Supabase for data.

Economics: $200–600/month in API spend. 4–6 weeks to a credible demo — and at least half that time should go to writing rubrics with practitioners, not writing code.

Direction 2 — Seatbelts for unsupervised agents

What: Once auto mode is default, small teams will discover they have no audit trail and no brake. Build the policy layer for indie devs and 5–50 person teams: command allow/deny lists, irreversible-action interception, per-project spend caps, replayable audit logs, anomaly alerts. Enterprise AISP platforms are priced and scoped for enterprises. The downmarket is empty.

Stack: Claude Code hooks + OpenTelemetry instrumentation + Postgres/Supabase for the audit stream + Cloudflare Workers as an edge policy layer. Ship it as an Agent Plugins 1.0 package — one build, six clients.

Economics: under $50/month infrastructure. MVP in 3–5 weeks. $15–40/seat/month is a defensible range.

Direction 3 — Private domain fine-tuning as a service

What: Soup CLI dropped 8B fine-tuning to a 4GB consumer GPU, which turns “a private model that never leaves your network” from a talking point into a deliverable. Target law firms, clinics, accounting practices, manufacturers — buyers whose compliance pressure exceeds their need for frontier intelligence. You deliver a domain model running on their hardware plus a refresh process.

Stack: Soup CLI (LoRA + layer streaming) for training · Ollama / llama.cpp for local serving · reuse Direction 1’s eval harness to prove quality · NVIDIA Build’s free model catalog for zero-cost selection testing before buying any hardware.

Economics: 2–4 weeks per client. $5k–20k upfront plus annual maintenance. Low-frequency, high-ticket — ten engagements a year is a living.

Direction 4 — Land grab in the Agent Plugins registry

What: The standard is days old and the plugin directories across six clients are essentially empty. Pick one high-frequency professional action — contract clause diffing, financial reconciliation, API contract testing, accessibility compliance checks — and ship one sharp plugin. This is a domain-name-rush window; the organic discovery bonus only happens once.

Stack: Follow the plugin.json spec from agentplugins/agent-plugins-example · MCP server in Node or Python · host on Vercel or Cloudflare Workers.

Economics: near-zero hosting, two weeks to v1. Go free to win installs and reviews, monetize advanced features later.

Counter-example worth remembering: OpenAI absorbing NextSlide shows that generic productivity is now claimed territory. Slide generators, general summarizers, all-purpose writing assistants — one platform update can zero them out. Safety lies where platforms won’t go: messy data, hard compliance, and standards that require domain experts to co-author.

Risk Factors

  • Platform absorption — NextSlide’s outcome is the pattern. Anything generic sitting on a platform’s roadmap is unpaid user research on their behalf.
  • Standard fragmentation — Agent Plugins 1.0 has five signatories, and MCP’s own author isn’t one of them. Decouple core logic from the distribution adapter before you bet on a format.
  • Accountability vacuum in auto mode — liability for destructive agent actions is genuinely unsettled. Set hard spend caps and sandboxes for yourself; put explicit responsibility language in client contracts.
  • Eval cold-start is real — an eval product is only as valuable as the expertise in its rubrics. Without practitioners deeply involved, you’ve built another scoreboard toy. Insiders can tell immediately.

Action Recommendations

If you’re pre-product / pre-revenue:

  • ✅ Read through the Harvey LAB repo structure this week, then hand-write 30 real tasks in your own industry using the same task/rubric organization. Fastest possible test of whether you have a genuine domain edge.
  • ✅ Prototype on Luna, not Sol. After an 80% cut, a few dozen dollars buys you a thousand iterations.
  • ✅ Stop building general assistants. List the three business processes you’ve understood best over the last three years and choose from that list — not from the trend feed.

If you have a shipped product or steady revenue:

  • ✅ Before August 14, audit every automation that depends on Claude Code. Set spend caps and sandbox boundaries now, not after the default flips.
  • ✅ Repackage your existing capability as an Agent Plugins 1.0 bundle. Marginal effort, six new distribution surfaces.
  • ✅ Revisit pricing. If you bill by usage to pass through token cost, move to outcome-based or per-seat billing — otherwise customers capture the entire price cut.
  • ✅ Build a regression eval suite. Every model upgrade can silently shift output quality; without evals, your first signal is a customer complaint.

What It Means

The build constraint is gone. Anyone can ship an app this quarter, for pocket change, into six distribution channels.

Which means shipping is no longer the achievement — and the scarce asset flipped from capability to proof. An 11% pass rate on real professional work says the last mile isn’t intelligence, it’s knowing what correct looks like and being able to demonstrate it repeatedly.

The builders who win the next two quarters won’t be the ones with the best prompts. They’ll be the ones who can hand a skeptical professional a number and say: here’s how often this is right, here’s how I measured it, here’s what happens when it isn’t.
