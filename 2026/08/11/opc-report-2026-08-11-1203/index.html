The Entire Agent Stack Just Shrank to Fit on a Raspberry Pi — So What Are You Actually Selling?

The Entire Agent Stack Just Shrank to Fit on a Raspberry Pi — So What Are You Actually Selling?

August 11, 2026

Key Insights

In the last 24 hours the agent stack collapsed from both ends simultaneously.

At the top, Ante shipped a complete coding agent — TUI, embedded ripgrep, local PDF/OCR, and a natively managed llama.cpp engine — as a single ~15MB Rust binary under Apache 2.0. No runtime dependencies, no node_modules, no account, fully offline. At the bottom, Cactus released Needle 2: a 45-million-parameter model for tool calling, device use, and structured extraction that ships as a 14MB file running a full session in 28MB of RAM, small enough to run on an ESP32-S3 microcontroller.

Read those two together and the conclusion is uncomfortable but clear: running an agent is no longer worth money. The harness is free. The model is becoming free. The only genuinely scarce thing left is context.

Which is exactly what Spotify published the same day. After thousands of engineers ran thousands of agent sessions, their bottleneck wasn’t speed — it was that “agents in one session would expend cycles rediscovering what another session had already resolved.” Their answer was Xirp, a vendor-neutral agentic development environment wired into their organizational knowledge source.

For a one-person business the instruction is blunt: stop building the Nth agent wrapper. Build the context layer, the verification layer, or the distribution channel that keeps agents from wasting motion.

Numbers that should change what you do this week:

  • 14MB / 28MB / 500 tok/s — Needle 2’s file size, peak session RAM, and decode speed on a Raspberry Pi 5. 45M parameters, Apache 2.0, weights on Hugging Face, 300–700 tok/s on sub-$200 Android phones. Marginal inference cost for an edge agent is now zero.
  • 15MB single binary, 998 stars, Rust — Ante’s entire footprint, with a pinned checksum-verified llama.cpp build (Metal on Apple silicon; CUDA, Vulkan, or CPU on Linux). The author’s own framing: “We care about the harness, not the model or the prompts.”
  • 12,987 stars, MIT — yc-software/qm, a “multiplayer agent harness for work,” in roughly three weeks. Open-source supply at the harness layer is now oversaturated.
  • $0 free tier, $9/user/month Pro — Docker Sandboxes pricing. Isolating agents costs nothing, which removes the last excuse for not doing it.

Market Trends

1. The harness layer commoditized, and open source did the killing

A year ago “an agent shell that loops, calls tools, and recovers from failure” was a product. Today it’s a weekend project.

Ante hit the Hacker News front page as a single-file binary (122 points, 75 comments). yc-software’s qm shipped a multiplayer agent harness under MIT and reached 12,987 stars and 1,505 forks. Perplexity open-sourced numbat (Apache 2.0, 879 stars) for on-device visibility into agent activity with optional pre-action blocking. Three different bets, three different shapes, one shared property: all free, and none of them expect the harness itself to be the business.

The more instructive part is the backlash. The top-voted objections to Ante weren’t technical — they were about distribution:

“Linking to a github repo for a binary release (no source code related to the agent that I could see) is a bit iffy IMO.”

“no source code”

And one commenter punctured the performance narrative entirely: “harnesses are simple loops, in theory should take very little memory even if written in python or typescript.” Another questioned the strategy itself: if frontier labs are betting the model matters most and bundling subsidized harnesses, betting purely on the harness is betting against the people who set the prices.

Translation: if your core pitch is “our agent loop is faster / leaner / better packaged,” three free projects erased your pricing power this week. And if you distribute as a closed binary, developers will question your trustworthiness before they evaluate your features.

2. Models are shrinking past the point where cloud is required — at two scales at once

Two data points, opposite ends, same direction.

Needle 2 trades wins with FunctionGemma 270M, LFM2.5 230M, and Apple FM on mobile device-use and tool-call benchmarks while being 5× to 70× smaller, and running at 2 bits against their f16.

The same day, Zuckerberg publicly attacked “closed” AI rivals in the FT as Meta returned to open models (419 points, 405 comments). Whatever you think of the messaging, the practical effect for builders is two Apache-2.0 options with no revenue thresholds and no rider clauses.

  • The story isn’t benchmarks, it’s the deployment envelope. Needle 2 fitting on an ESP32-S3 means agents can now live in sensors, wearables, robots, and vehicles — categories that were previously not even worth scoping.
  • Two sizes, two businesses. 30B local solves privacy-sensitive desktop agents. 45M edge solves “put a small tool-calling brain inside a physical product.” Competitive density in the second is dramatically lower.
  • Both licenses are actually usable commercially. That’s a hard prerequisite for hardware and client delivery work, and it is now satisfied.

3. The real bottleneck surfaced: context, not capability

Spotify’s postmortem, published yesterday by Tyson Singer, is the highest-signal primary source this cycle. Every CTO he speaks with has moved past the adoption question. What happens next is the interesting part:

  • Engineers — and later non-engineers — began orchestrating multiple agents in parallel, across sessions, tools, repositories, and branches.
  • Context accumulated in one session but was needed in another. Institutional knowledge fragmented into individual configurations: scattered CLAUDE.md files, bespoke MCP setups, personal prompt libraries.
  • The result: “PRs increased, but so did rework, inconsistency, and wasted tokens. Agents in one session would expend cycles rediscovering what another session had already resolved.”
  • Engineers were “investing as much effort reconstructing context as they were on building new capabilities.”

Their stated motivation for building vendor-neutral is worth quoting because it’s a pricing observation, not an architecture one: new models, new agents, rising costs, and “pricing structures that shift quarter to quarter.” The goal was flexibility to swap any layer “without accumulating vendor dependency or compounding costs as you scale.”

Corroborating signal from the indie side: VictorTaelin’s OptMem — “Permanent memory for AI agents. A 426-token prompt, a script, plug and play” — pulled 1,226 stars in about three weeks. When a 426-token memory hack earns four figures in stars, the underlying need is wildly underserved.

4. “Token-efficient language” folk wisdom just failed replication

Dan Luu published a systematic teardown (87 points on HN) of the widely-cited claim that dynamic languages are more token-efficient and therefore better for AI coding. The original work claimed a 2.6× gap between C and Clojure, and that J averaged just 70 tokens, “dominating” everything.

He re-ran it on a task with actual surface area: hand an agent the zstd RFC and have it implement a complete zstd decoder, in a container with no internet, with no tests provided.

  • At medium effort, dynamic languages did cluster slightly better. At ultra effort the results were thoroughly mixed, with more static than dynamic languages among the top performers.
  • The original evaluation used Rosetta Code problems. A task solvable in 70 tokens isn’t a task. Performance on trivial problems doesn’t generalize — the same pattern he found when comparing trivial vs. non-trivial “caveman mode” evals.
  • The second commonly-cited benchmark had a fatal defect: a test executed a nonexistent path, and a later agent symlinked that path to its own executable — so every subsequent test ran that one agent’s binary. Conclusions drawn about Rust’s failure rate from that data are meaningless.
  • The robust finding: a weak-to-moderate positive correlation where more popular languages produce more correct and cheaper solutions, plausibly because labs invest little or no synthetic RL environment effort on obscure languages.

Actionable version: don’t pick Clojure, J, or anything exotic to save tokens. Pick whichever of TypeScript, Python, Go, or Rust you know best. Token savings won’t cover the rework cost of thin training coverage.

5. A deployment reality check: a pharmacy chain pulled its voice agent

Kinney Drugs launched Burt, an AI phone assistant handling prescriptions and refills, in May. In August, after hundreds of customer complaints, they reverted inbound calls to a classic touch-tone system. Reported failures: incoherent calls, wrong dosages, missed prescription notifications.

President John Marraffa’s line is worth memorizing verbatim:

“Getting privacy and security right does not mean we got the experience right. We did not, and we own that.”

He noted Burt is fully HIPAA compliant, not open-source, and doesn’t generate or manipulate data. None of that saved it.

What they kept is the actual lesson. Burt survives for outbound communication — refill texts — and patients must opt in. That draws a hard product boundary:

  • Outbound + structured + opt-in = viable.
  • Inbound + open-ended + high-stakes domain = not viable today.

Compliance is not armor. They cleared HIPAA and still got pulled on experience.

Build Directions

The four trends converge on one gap: running an agent is worthless; making it run correctly, cheaply, or somewhere nobody else can run it is valuable. Ordered by ascending competitive density.

1. Embedded agents — tool calling inside hardware (lowest competition)

What to build: Needle 2 makes a 45M-param, 14MB, 28MB-RAM tool-calling model viable on ESP32-S3, Pi 5, and Quest 3S. That unlocks a class of products that simply didn’t scope before: smart-home controllers that parse natural language locally, retail kiosk voice ordering, industrial sensors doing on-device anomaly triage, robots sequencing multi-step actions. The shared trait is can’t or won’t connect to the cloud, and latency matters.

Stack: Needle 2 (Apache 2.0, weights on Hugging Face) + the Cactus engine (5,599 stars — quantization, kernels, runtime) + ESP32-S3 ($3–8/unit) or Raspberry Pi 5 ($60–80).
Fit: tool calling, device use, structured extraction, intent routing. Do not expect long-form reasoning.
Cost & timeline: zero marginal inference cost; 2–4 weeks to prototype. Your real costs are hardware sourcing and field debugging, not tokens.

2. A context layer for small teams — Spotify’s problem at SMB pricing

What to build: Spotify solved context fragmentation with Xirp + Portal. The same pathology exists in any 5–50 person engineering team, and none of them can afford or staff a Backstage deployment. Build a lightweight repo-level context service: unify CLAUDE.md/AGENTS.md, MCP configs, prompt libraries, and architecture decision records, then expose them to any harness over MCP. The headline feature is vendor neutrality — Spotify said it themselves, pricing structures shift quarterly and customers want the freedom to swap.

Stack: an MCP server (TypeScript/Python) + Supabase or Postgres with pgvector for retrieval + the minimalist memory approach OptMem validated (1,226 stars). Do not start with heavyweight RAG.
Fit: teams already running Claude Code / Codex / qm across parallel sessions — i.e. teams already burning tokens on rediscovery.
Cost & timeline: 4–8 weeks to MVP. Price in the $15–16/user/month band Docker Team occupies; buying decisions at that tier are fast.

3. Agent governance and audit trails for regulated small shops

What to build: Docker put sandboxing in the free tier and Perplexity open-sourced endpoint-level agent visibility with pre-action blocking (numbat, Apache 2.0). The primitives are free; assembling them into an auditable evidence chain is not being done. Target small organizations that must prove what an agent touched: accounting firms, small healthcare providers, law practices, contractors serving government clients. You’re not selling interception — you’re selling exportable behavior logs and forensic reconstruction reports.

Stack: Docker Sandboxes (from $0) for isolation + numbat for on-device detection and pre-action blocking + your own audit event stream and report export.
Fit: invert the Kinney lesson — plenty of small shops can tolerate imperfect UX but cannot produce an evidence chain when asked.
Cost & timeline: zero-cost primitives; 6–10 weeks to a demoable product. Classic high-ticket, low-logo-count business.

4. Offline and air-gapped agent delivery

What to build: Ante proved a full coding agent fits in a 15MB offline binary; Muse Glimmer supplies an Apache-2.0 30B under 20GB. Package both into a drop-in offline agent workstation for clients who cannot send code or data to the cloud. Note that Ante got hammered on HN for binary-only distribution — that’s your opening. Do the same thing with auditable source. Trust is the differentiator.

Stack: Muse Glimmer 30B (Apache 2.0, <20GB at 4-bit) + llama.cpp / Ollama / MLX runtime + your own auditable harness. Hardware: an M4-Max or a single 5090.
Fit: defense-adjacent contracting, healthcare data work, M&A diligence, any engagement under a strict NDA.
Cost & timeline: $3,000–6,000 one-time hardware. Bill per project, not per seat. Zero marginal inference cost is your core price advantage against cloud-based competitors.

5. Narrow voice agents — outbound only, structured only (highest competition, but the boundary is now known)

What to build: Kinney Drugs ran the market research for everyone at the cost of hundreds of complaints. The viable half is outbound, structured, opt-in. So don’t build an AI receptionist. Build appointment confirmations, refill reminders, delivery notifications, satisfaction follow-ups — flows where the script is deterministic and failure degrades silently to SMS. Any time the model is uncertain, hand off to a human or drop to text. Never improvise.

Stack: a realtime voice runtime (qwen-audio-agent, 2,063 stars, is one open option) or a commercial voice API + a deterministic state machine controlling flow — do not let the LLM drive control flow + a mandatory human fallback path.
Fit: dental practices, auto shops, veterinary clinics, local service businesses. Low stakes, high repetition, scripted.
Cost & timeline: 4–6 weeks. Categorically avoid medical dosing, financial advice, and legal opinions.

Risk Factors

  • The harness layer is a red ocean and your competitors are free. qm at 12,987 stars, Ante at 998, numbat at 879 — mostly MIT or Apache 2.0. Any paid product whose core value proposition is “a better agent shell” lost its pricing power this week.
  • Closed-binary distribution kills trust before it kills conversion. The top-voted criticism of Ante was “no source code,” not any technical flaw. When selling to developers, how you ship is part of the product.
  • Passing compliance does not mean the product works. Burt was fully HIPAA compliant, closed-source, and non-generative, and still got pulled from inbound service for stating wrong dosages. In high-stakes verticals, an experience failure means removal, not iteration.
  • Most “token-saving tricks” are untested folklore. The widely-cited 2.6× dynamic-language advantage rests on trivial problems and a benchmark corrupted by a symlink. Before adopting any such finding, check what difficulty of task produced it.
  • Vendor lock-in compounds faster than it used to. Spotify explicitly flagged that models, agents, and pricing structures shift quarter to quarter. Any architecture that hard-codes business logic into one model API is accruing a liability that gets repriced every quarter.

Action Recommendations

If you’re starting out (no paying users yet)

  • Run Needle 2 this week. There’s a WebAssembly playground in the browser with smart-home multi-step, three-move robot, form-filling, and off-topic-refusal examples. Spend two hours mapping what 45M parameters can and cannot do. That boundary is your idea filter.
  • Don’t build a harness. Build context. If your concept includes “a better agent loop,” pivot. Redirect that effort toward stopping agents from rediscovering known information.
  • Default to a mainstream language. TypeScript, Python, Go, or Rust — whichever you know best. Exotic-language token savings don’t cover the rework from thin training coverage.
  • If you do voice, do outbound only. Write the Kinney boundary into your product definition as a hard constraint: outbound, structured, opt-in, always degradable to SMS.

If you’re already operating (revenue, customers)

  • Audit context waste this week. Use Spotify’s checklist: across your parallel agent sessions, how many tokens go to rediscovering what another session already resolved? The number is usually uncomfortable.
  • Make the model layer swappable. Spotify says pricing shifts quarterly. A thin abstraction between your calls and your business logic is a day of work now and a quarter of work when you’re forced to migrate.
  • Evaluate moving workloads local. Muse Glimmer is Apache 2.0 and under 20GB at 4-bit; an M4-Max or a single 5090 carries it. For always-on, non-peak background tasks, marginal inference cost can go to zero.
  • Sandbox your agents now. Docker Sandboxes is in the free tier. Solve isolation before a customer asks what your agent can touch — and they will ask.
  • If you’re shipping closed binaries, reconsider. Ante’s comment thread is free user research: developers interrogate distribution before they evaluate features.

Quick Data Reference

  • 14MB file / 28MB session RAM / 45M params — Needle 2, Apache 2.0. 800+ tok/s prefill and 500+ tok/s decode on a Raspberry Pi 5; 300–700 tok/s on sub-$200 phones; runs on ESP32-S3. 5× to 70× smaller than comparable small models.
  • ~15MB single binary — Ante coding agent, Rust, Apache 2.0, 998 stars, 23 forks. Embeds TUI, ripgrep, PDF/OCR, and a verified llama.cpp build. Fully offline, no account.
  • 30B / 4-bit / <20GB — Meta Muse Glimmer, Apache 2.0, trained for long-horizon execution and failure recovery. 1,063 points on HN. Runs on a single consumer GPU.
  • 12,987 stars / 1,505 forks (MIT) — yc-software/qm. For comparison: Comp AI’s agent-first CRM 8,130 (MIT), Perplexity numbat 879 (Apache 2.0), Cactus engine 5,599.
  • $0 free / $9 Pro / $15 Team / $24 Business per user/month — Docker pricing (annual). Agent isolation has no cost barrier left.
  • ~7.4% spread — Stoa Markets (YC S26) illustrative gap on an 8-node H100 trade: $1.95M on-venue vs $2.10M off-market. GPU spot markets still lack shared price discovery, and that spread is the intermediary’s business model.

What It Means

Both ends of the agent stack collapsed in the same 24 hours. A full coding agent now fits in 15MB offline; a working tool-calling model fits in 14MB on a microcontroller. When execution becomes free, value migrates to whatever execution still can’t supply on its own — and Spotify just told us what that is, at the cost of thousands of wasted sessions: context.

The teams shipping free harnesses aren’t being generous. They’re conceding that the layer is worthless and racing to own what sits above and below it. A one-person business should draw the same conclusion faster, because you can act on it in a week rather than a quarter. Build the memory, the audit trail, the offline delivery, or the embedded product — the places where being small is an advantage and where “we run an agent” is a feature, not the pitch.
